# 双均线择时策略量化回测系统

## 项目简介
本项目为量化交易课程作业。采用模块化架构，将双均线择时策略（MA5/MA20 金叉买入、死叉卖出）拆分为数据层、计算层、回测层和展示层。系统包含真实回测内核，支持输出净值曲线与四大绩效指标（累计收益、年化收益、最大回撤、夏普比率）。

## 代码文件架构
- `config.py`: 全局参数配置（起止时间、均线窗口等）
- `data_layer.py`: 数据层（基于 akshare 获取数据、处理停牌对齐）
- `calc_layer.py`: 计算层（MA均线计算、防未来函数的信号生成）
- `backtest_layer.py`: 回测层（逐日撮合、扣除佣金、计算指标）
- `view_layer.py`: 展示层（生成 HTML 净值图与 CSV 明细）
- `main.py`: 主程序入口（串联各层）

## 如何复现运行
1. **安装依赖**：
   确保电脑已安装 Python，在命令行运行：
   `pip install -r requirements.txt`
   *(注：若未安装 akshare 或网络无法访问财经接口，代码会自动降级使用本地演示数据，确保算法逻辑可成功复现)*
2. **运行回测**：
   在命令行运行主程序：
   `python main.py`
3. **查看报告**：
   运行完成后，当前目录下会自动生成 `backtest_report.html`。用浏览器打开即可查看策略与基准的归一化净值对比图及买卖点。
